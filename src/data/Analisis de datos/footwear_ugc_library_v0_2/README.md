# Luz AI Studio Footwear UGC Library v0.2

Contiene 31 assets generados desde el set `pov zapatos.zip`.

## Uso rápido

1. Elegir un asset por `archetype`, `tags` o `fingerprint`.
2. Reemplazar `{{FOOTWEAR_INPUT}}` por una descripción textual o por una instrucción de imagen de referencia.
3. Enviar `prompt` + `negative_prompt` al generador.

## Principio visual

El protagonista siempre es el calzado. La escena solo funciona como excusa visual creíble para decir: “mira mis zapatos”, sin caer en catálogo ni estudio.

## Archivos

- `footwear_engine.json`: reglas globales y slots.
- `scene_archetypes.json`: familias de composición.
- `assets.json`: 31 assets listos.
- `tags.json`: índice de tags para búsqueda.
