# Photodump Flow Prototype

Prototipo navegable de la nueva interfaz de Photodump, basado en la lógica vigente de `Luz-Ai-Studio/src/modules/photodump`.

## Alcance

- Seis recetas listas: Unboxing / Producto, Outfit Check, Haul de ropa, Favoritos de la semana, Varios looks y Muestra un look.
- Flujo de cuatro pasos: elegir receta, completar inputs, creación en vivo y resultados.
- Controles de referencia, formato de publicación, contexto/brief, opciones por receta y créditos.
- Reglas reflejadas: `Muestra un look` fija en 3 resultados; las otras recetas pueden variar entre 1 y 8 en este prototipo.

## Uso

Abrir `index.html` en cualquier navegador. No requiere instalación ni dependencias.

## Nota de implementación

Es una validación UX visual e interactiva. Todavía no reemplaza los componentes React del módulo ni ejecuta generación real.
